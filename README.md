# Al Ahd General Contracting - Cinematic Digital Experience

Award-winning industrial construction company website built with Next.js, GSAP, Three.js, and Tailwind CSS.

## Project Overview

This is a production-ready, cinematic website experience for Al Ahd General Contracting, communicating industrial authority, precision engineering, and scale.

## Tech Stack

- **Framework**: Next.js 14 (App Router)
- **Styling**: Tailwind CSS + CSS Modules
- **Animation**: GSAP, Framer Motion
- **3D Graphics**: Three.js, React Three Fiber
- **Smooth Scroll**: Lenis
- **Forms**: React Hook Form + Zod
- **Type Safety**: TypeScript (strict mode)

## Getting Started

### Installation

```bash
npm install
# or
yarn install
# or
pnpm install
```

### Development

```bash
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) in your browser.

### Build

```bash
npm run build
npm start
```
